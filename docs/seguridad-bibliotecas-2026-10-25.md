# Actualización de seguridad — 25 de octubre de 2026

Actualizo las referencias de Firebase JavaScript 10.14.1 y jsPDF 4.2.1 en 27 archivos del proyecto.

La revisión contrasta los avisos de npm/GitHub y la distribución oficial de SheetJS. Se comprueban los scripts de los HTML modificados, la autenticación y conexión reales de Firebase 10.14.1 para las plataformas que lo utilizan, y el rechazo de lecturas anónimas de registros privados. Se comprueba la generación municipal de planillas carta con jsPDF 4.2.1 y AutoTable 3.8.2: dos modalidades, dos páginas y revisión de sus imágenes renderizadas. Se verifica también la descarga de certificados de FUNCECAIND con textos largos. Las pruebas usan datos sintéticos.

Las actualizaciones conservan las reglas, los roles y los registros de las aplicaciones. La bitácora del Centro de Control mantiene el seguimiento para el próximo informe quincenal.

Fuentes: [Firebase](https://github.com/advisories/GHSA-3wf4-68gx-mph8), [jsPDF](https://github.com/parallax/jsPDF/security/advisories), [SheetJS](https://docs.sheetjs.com/docs/getting-started/installation/standalone/).
